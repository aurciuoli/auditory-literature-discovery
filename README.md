# Auditory Literature Discovery and Screening

This is a non-commercial academic research project developing a Python-based workflow for systematic discovery and screening of scientific publications.

The initial application focuses on auditory function in mammals, including primates, using bibliographic databases to identify publications reporting hearing thresholds, audiograms, auditory evoked responses, otoacoustic emissions, and related auditory measurements.

The software combines bibliographic search, metadata collection, deduplication, abstract retrieval, and researcher-led relevance screening. The current implementation uses multiple scholarly information sources, with the aim of improving the reproducibility and comprehensiveness of literature searches.

The application is intended for academic research and may subsequently be developed into a reusable tool for the research community.

Bibliographic records retrieved through licensed APIs are handled in accordance with the relevant provider terms, institutional licences, and data-use restrictions. API credentials are kept separate from the public source code and website.

**Application type:** Local Python research software  
**Purpose:** Non-commercial academic research  
**Initial research domain:** Auditory biology and mammalian hearing
